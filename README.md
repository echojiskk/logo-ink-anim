# 镜界 · 水墨启动动画（JINGJIE Ink Logo Animation）

工作室「镜界」（JINGJIE）的水墨风格 Logo 启动动画——纯 SVG + CSS 动画实现，**零图片、零依赖、单文件**，打开即播，约 3.4s 定格。

## 在线预览

开启 GitHub Pages 后：

```
https://<用户名>.github.io/logo-ink-anim/
```

## 本地运行

无需任何环境，双击 `index.html` 即可在浏览器播放；右下角「重播」按钮可重新播放。

## 技术要点

- **纯 SVG 美术**：山体、墨点、雾气、「镜界」二字全部为 SVG 路径与渐变（`linearGradient` / `radialGradient`），不含任何位图资源
- **CSS 动画驱动**：所有动效由 `@keyframes` + `animation-delay` 错峰编排，GPU 友好的 `opacity` / `transform` 为主
- **倒影分区**：水面倒影通过 `clipPath` 分区裁剪（8 切片），倒影层带 SVG `transform` 定位，因此动画只驱动 `opacity`，避免覆盖定位
- **只写 from 帧**：关键帧只定义起始状态，终点自动取元素自身基础值——各图层浓度（透明度）被完整保留，不会出现「动画结束后变浓/变淡」
- **重播机制**：JS 保存 SVG 初始 `outerHTML`，点击重播时重新插入 DOM
- **兜底定格**：3.4s 后强制清除动画属性回到终态；并用 `getAnimations()` 早期探测——浏览器未调度动画时（部分 WebView / 省电模式）立即点亮，避免黑屏

## 设计说明

- 配色为宣纸色底（`#f5f1e8`）+ 单色墨韵，全部图形用同一墨色（`#1a1a1a`）的不同透明度表现浓淡干湿
- 版本对比：早期版 `splash_ink.html` 采用 Songti 宋体衬线 + 圆角卡片式舞台；最终版改为 KaiTi 楷体、全屏无边框舞台，并确定保留水中倒影
